# Lysning — Glossary

Shared vocabulary for the marketing site so copy stays consistent. Product terms are sourced
from the app docs (`~/src/salvyn/docs`); the app was renamed **Salvyn → Lysning**.

| Term | Meaning | Copy rule |
|---|---|---|
| **Lysning** | The app (personal financial planner + behavior-change). Formerly "Salvyn". | Always "Lysning". Never "Salvyn" in public copy. |
| **Safe-to-Spend (STS)** | The one honest number: what's actually safe to spend today, after reconciliation + earmarks. The product's wedge. | Capitalize. This is the hero concept. |
| **Earmark / earmarked** | Goals set aside *real money in real accounts*: `available = balance − Σ earmarks`. The same rupee is never committed twice. | Use to explain "we never hold your money". |
| **No custody / your money stays yours** | Lysning never holds, moves, or auto-invests money (unlike Plum/Albert/Jar). Amounts are earmarked, not transferred. | A trust proof point — not the hero. |
| **Local-first / on-device** | Free tier runs fully on the phone; no account, no server, no data egress (only opt-in anonymous analytics). | Trust proof, not the hook. |
| **Trust → Ritual → Foresight** | The essentialness ladder: believe the number, check it daily, pay for what's next. | Structures the "how it works" story. |
| **The Sanctuary** | Design philosophy: calm, judgment-free, no red, no scores. Orientation not management. | Governs site tone + visuals. |
| **Reconciliation** | Netting out refunds, transfers, and "owed by others" so balances reflect real money. | Explains *why* STS is trustworthy. |
| **Freemium (free tier)** | Fully on-device core: STS, goals, ingestion, budgets (Plans), reports, CSV export. India launch is free. | "Free" = this tier. |
| **Premium** | Backend-connected: AA sync, household, cloud backup, alerts, LLM Q&A. Sells *foresight/results*, never privacy. | Roadmap — confirm if mentioned on site. |
| **Account Aggregator (AA)** | India's consented bank-connectivity framework (SETU/FINVU). Premium, opt-in. | Only if we discuss sync. |
| **Salaried saver** | Primary India persona: 20–50, salary-earning individuals/couples, UPI-heavy, goal-driven. | Site's target reader. |

## Voice (from `design-guidelines.md` §7)
- A **thoughtful friend at a coffee shop**, never a financial advisor in a suit.
- **No moral money vocabulary** — no "over budget", "failed", "good/bad month".
- **No red, ever.** Calm amber/evergreen. Numbers are facts, not verdicts.
- Describe → project → offer a path. Every state has a next step.
